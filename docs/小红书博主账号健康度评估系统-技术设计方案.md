## 1. 项目概述

### 1.1 背景与目标

小红书（RED）已成为国内核心的内容种草平台，博主账号的健康状态直接影响其商业价值和运营策略。本系统旨在构建一套**生产级**的账号健康度评估平台，实现对博主账号的多维度、自动化、持续性健康监测与评分。

**核心目标：**

- 对小红书博主账号进行全维度健康度评估，输出可量化的健康评分（0-100 分）
- 支持批量监控多个账号，提供横向对比与趋势分析
- 及时发现账号异常（限流、违规、互动骤降等），触发告警通知
- 为运营决策提供数据支撑（博主筛选、投放评估、账号优化建议）

### 1.2 适用场景

| 场景 | 说明 |
|------|------|
| MCN 机构管理 | 批量监控旗下博主账号健康状态，及时发现异常 |
| 品牌方投放评估 | 评估合作博主账号质量，降低投放风险 |
| 博主自我诊断 | 了解自身账号健康状态，获取优化建议 |
| 行业研究分析 | 赛道内账号健康度大盘分析与趋势洞察 |

### 1.3 设计原则

- **合规优先**：所有数据获取严格通过合法渠道，不触碰法律红线
- **高可用**：系统可用性目标 ≥ 99.9%
- **可扩展**：模块化设计，支持指标体系、数据源、评分模型的灵活扩展
- **可解释**：评分结果可下钻到具体指标，每个扣分项有明确原因
- **数据驱动**：评分权重可配置，支持不同业务场景的差异化需求

## 3. 指标体系与评分模型

### 3.1 指标体系总览

```
账号健康度 (Account Health Score)
├── 数据指标维度 (Data Metrics) — 权重 W1
│   ├── 粉丝增长趋势
│   ├── 互动率
│   ├── 曝光量趋势
│   └── 发布活跃度
├── 内容质量维度 (Content Quality) — 权重 W2
│   ├── 内容原创率
│   ├── 内容垂直度
│   ├── 爆款率
│   └── 内容质量指数 (CQI)
├── 合规与风险维度 (Compliance & Risk) — 权重 W3
│   ├── 违规记录
│   ├── 广告标注合规率
│   ├── 内容审核通过率
│   └── 异常行为检测
└── 转化能力维度 (Conversion) — 权重 W4
    ├── 商业合作报价合理性
    ├── 粉丝画像质量
    └── 历史合作效果
```

### 3.2 各维度指标详情

#### 3.2.1 数据指标维度

| 指标名称 | 计算公式 | 数据来源 | 健康阈值 |
|---------|---------|---------|---------|
| 粉丝总量得分 | 基于粉丝量分档映射（<1k/1k-10k/10k-50k/50k-100k/>100k） | 蒲公英/第三方 | 分档评分 0-100 |
| 粉丝增长率 | (当前粉丝 - 上期粉丝) / 上期粉丝 × 100% | 第三方平台 | >0% 正常，>5% 优秀 |
| 日均互动率 | (点赞+收藏+评论+分享) / 阅读量 | 蒲公英/第三方 | ≥3% 合格，≥5% 优秀 |
| 收藏率 | 收藏数 / 阅读量 | 蒲公英/第三方 | ≥5% 反映实用价值 |
| 评论率 | 评论数 / 阅读量 | 蒲公英/第三方 | ≥0.5% 反映参与深度 |
| 曝光量趋势 | 近 30 天曝光量移动平均 vs 前 30 天 | 创作者中心/第三方 | 持续上升为健康 |
| 发布频率 | 近 30 天发布笔记数 / 30 | 自行统计 | ≥0.5 篇/天为活跃 |

#### 3.2.2 内容质量维度

| 指标名称 | 计算方式 | 数据来源 | 健康阈值 |
|---------|---------|---------|---------|
| 内容原创率 | 原创笔记数 / 总笔记数 × 100% | 蒲公英 | ≥80% 为健康 |
| 内容垂直度 | 基于笔记分类/标签的聚类离散度（逆指标） | 第三方平台 | 离散度 < 0.3 为聚焦 |
| 爆款率 | 阅读量 > 账号均值 3 倍的笔记占比 | 第三方平台 | ≥10% 为优秀 |
| 内容质量指数 (CQI) | w1×点赞率 + w2×收藏率 + w3×评论率 + w4×分享率 | 综合计算 | ≥5% 为优秀 |
| 系列化程度 | 存在连续系列内容的笔记占比 | 自行分析 | ≥20% 为良好 |
| 内容形式多样性 | 图文/视频/直播的内容比例均衡度 | 第三方平台 | 不过度依赖单一形式 |

#### 3.2.3 合规与风险维度

| 指标名称 | 评估方式 | 数据来源 | 健康阈值 |
|---------|---------|---------|---------|
| 违规记录 | 近 180 天内是否有平台处罚记录 | 蒲公英/人工审核 | 无违规为满分 |
| 广告标注合规率 | 正确标注"广告"的合作笔记占比 | 人工审核/规则匹配 | 100% 为合规 |
| 内容审核通过率 | 首次发布审核通过的笔记占比 | 创作者中心 | ≥95% 为健康 |
| 异常行为检测 | 检测刷粉、刷赞、异常登录等行为 | 数据分析引擎 | 无异常为满分 |
| 限流风险指数 | 基于多指标综合判断的限流概率 | 模型计算 | <10% 为安全 |

#### 3.2.4 转化能力维度

| 指标名称 | 评估方式 | 数据来源 | 健康阈值 |
|---------|---------|---------|---------|
| 粉丝画像质量 | 粉丝年龄/性别/地域分布与目标受众匹配度 | 第三方平台 | 匹配度 ≥60% |
| CPE（单次互动成本） | 合作报价 / 平均互动数 | 蒲公英 | 低于赛道均值为优 |
| 历史合作效果 | 品牌合作笔记的平均表现 vs 账号日常表现 | 蒲公英/第三方 | ≥日常表现的 80% |
| 商业价值稳定性 | 近 6 个月商业指标波动幅度 | 综合计算 | 波动 < 20% 为稳定 |

### 3.3 评分模型设计

#### 3.3.1 综合评分公式

```
HealthScore = W1 × DataScore + W2 × ContentScore + W3 × ComplianceScore + W4 × ConversionScore
```

#### 3.3.2 默认权重配置

| 场景 | W1 (数据指标) | W2 (内容质量) | W3 (合规风险) | W4 (转化能力) |
|------|-------------|-------------|-------------|-------------|
| 通用评估 | 0.30 | 0.30 | 0.25 | 0.15 |
| 品牌投放 | 0.20 | 0.25 | 0.30 | 0.25 |
| MCN 管理 | 0.30 | 0.25 | 0.25 | 0.20 |
| 达人筛选 | 0.25 | 0.30 | 0.20 | 0.25 |

#### 3.3.3 维度评分计算

每个维度内的指标采用**加权平均 + 异常惩罚**机制：

```
DimensionScore = Σ(Wi × IndicatorScorei) - PenaltyScore
```

**异常惩罚规则：**

| 异常类型 | 惩罚分值 | 触发条件 |
|---------|---------|---------|
| 违规处罚 | -20 ~ -40 | 近 180 天有平台处罚记录 |
| 限流信号 | -15 ~ -30 | 曝光量连续 7 天下降 > 30% |
| 刷量嫌疑 | -25 ~ -50 | 互动数据异常波动（标准差 > 3σ） |
| 停更风险 | -10 | 连续 14 天未发布内容 |
| 粉丝异常流失 | -15 | 单日粉丝净流失 > 1% |

#### 3.3.4 健康等级划分

| 等级 | 分值范围 | 颜色标识 | 说明 |
|------|---------|---------|------|
| A（优秀） | 85-100 | 🟢 绿色 | 账号状态极佳，可持续投入 |
| B（良好） | 70-84 | 🔵 蓝色 | 账号整体健康，有优化空间 |
| C（一般） | 55-69 | 🟡 黄色 | 存在明显短板，需关注优化 |
| D（较差） | 40-54 | 🟠 橙色 | 多项指标异常，建议重点干预 |
| E（危险） | 0-39 | 🔴 红色 | 账号存在严重问题，建议暂停合作 |

### 5.2 采集容错设计

```python
import asyncio
from typing import Callable, TypeVar
from functools import wraps

T = TypeVar('T')


class CollectionRetry:
    """采集重试装饰器"""

    def __init__(
        self,
        max_retries: int = 3,
        backoff_factor: float = 2.0,
        retryable_exceptions: tuple = (Exception,),
    ):
        self.max_retries = max_retries
        self.backoff_factor = backoff_factor
        self.retryable_exceptions = retryable_exceptions

    def __call__(self, func: Callable[..., T]) -> Callable[..., T]:
        @wraps(func)
        async def wrapper(*args, **kwargs) -> T:
            last_exception = None
            for attempt in range(self.max_retries):
                try:
                    return await func(*args, **kwargs)
                except self.retryable_exceptions as e:
                    last_exception = e
                    wait_time = self.backoff_factor ** attempt
                    await asyncio.sleep(wait_time)
            raise last_exception  # type: ignore

        return wrapper


class RateLimiter:
    """API 频率限制器"""

    def __init__(self, max_calls: int, period: float):
        self.max_calls = max_calls
        self.period = period
        self.calls: list[float] = []

    async def acquire(self):
        import time
        now = time.monotonic()
        # 清理过期记录
        self.calls = [t for t in self.calls if now - t < self.period]
        if len(self.calls) >= self.max_calls:
            sleep_time = self.period - (now - self.calls[0])
            await asyncio.sleep(sleep_time)
        self.calls.append(time.monotonic())
```

### 6.2 数据清洗规则

```python
class DataCleaner:
    """数据清洗处理器"""

    @staticmethod
    def clean_interaction_data(df: pd.DataFrame) -> pd.DataFrame:
        """清洗互动数据"""
        # 1. 去除重复记录
        df = df.drop_duplicates(subset=['note_id', 'data_date'])

        # 2. 处理缺失值
        numeric_cols = ['read_count', 'like_count', 'collect_count',
                        'comment_count', 'share_count']
        for col in numeric_cols:
            df[col] = df[col].fillna(0).clip(lower=0)

        # 3. 异常值检测与处理 (IQR 方法)
        for col in numeric_cols:
            Q1 = df[col].quantile(0.25)
            Q3 = df[col].quantile(0.75)
            IQR = Q3 - Q1
            upper_bound = Q3 + 3 * IQR
            df.loc[df[col] > upper_bound, f'{col}_flag'] = 'outlier'

        # 4. 数据类型校验
        df['publish_time'] = pd.to_datetime(df['publish_time'], errors='coerce')
        df = df.dropna(subset=['publish_time'])

        return df

    @staticmethod
    def calculate_derived_metrics(df: pd.DataFrame) -> pd.DataFrame:
        """计算衍生指标"""
        # 互动率
        df['interaction_rate'] = (
            (df['like_count'] + df['collect_count']
             + df['comment_count'] + df['share_count'])
            / df['read_count'].replace(0, np.nan)
        ).fillna(0)

        # 收藏率
        df['collect_rate'] = (
            df['collect_count'] / df['read_count'].replace(0, np.nan)
        ).fillna(0)

        # 评论率
        df['comment_rate'] = (
            df['comment_count'] / df['read_count'].replace(0, np.nan)
        ).fillna(0)

        # 内容质量指数 (CQI)
        df['cqi'] = (
            0.25 * df['like_count']
            + 0.35 * df['collect_count']
            + 0.25 * df['comment_count']
            + 0.15 * df['share_count']
        ) / df['read_count'].replace(0, np.nan)

        return df
```

## 8. 健康评分引擎设计

### 8.1 评分引擎核心逻辑

```python
from dataclasses import dataclass, field
from typing import Optional
from enum import Enum
import numpy as np


class HealthLevel(Enum):
    A = ("优秀", 85, 100)
    B = ("良好", 70, 84)
    C = ("一般", 55, 69)
    D = ("较差", 40, 54)
    E = ("危险", 0, 39)

    @classmethod
    def from_score(cls, score: float) -> "HealthLevel":
        for level in cls:
            if level.value[1] <= score <= level.value[2]:
                return level
        return cls.E


@dataclass
class ScoreWeights:
    """评分权重配置"""
    w_data: float = 0.30
    w_content: float = 0.30
    w_compliance: float = 0.25
    w_conversion: float = 0.15

    def validate(self):
        total = self.w_data + self.w_content + self.w_compliance + self.w_conversion
        if not np.isclose(total, 1.0, atol=0.01):
            raise ValueError(f"权重之和必须为 1.0，当前为 {total}")


@dataclass
class DimensionScore:
    """维度评分"""
    name: str
    score: float
    max_score: float = 100.0
    indicators: dict = field(default_factory=dict)
    penalty: float = 0.0
    penalty_reasons: list[str] = field(default_factory=list)

    @property
    def final_score(self) -> float:
        return max(0.0, min(100.0, self.score - self.penalty))


@dataclass
class HealthScoreResult:
    """健康评分结果"""
    account_id: int
    platform_uid: str
    score_date: str
    total_score: float
    health_level: str
    dimensions: dict[str, DimensionScore]
    weights: ScoreWeights
    suggestions: list[str] = field(default_factory=list)


class HealthScoreEngine:
    """健康评分引擎"""

    def __init__(self, weights: Optional[ScoreWeights] = None):
        self.weights = weights or ScoreWeights()

    def calculate(
        self,
        account_id: int,
        platform_uid: str,
        score_date: str,
        account_data: dict,
        notes_data: list[dict],
        compliance_data: dict,
    ) -> HealthScoreResult:
        """计算综合健康评分"""

        # 1. 计算各维度评分
        data_dim = self._calc_data_dimension(account_data, notes_data)
        content_dim = self._calc_content_dimension(account_data, notes_data)
        compliance_dim = self._calc_compliance_dimension(compliance_data)
        conversion_dim = self._calc_conversion_dimension(account_data)

        # 2. 计算综合评分
        total_score = (
            self.weights.w_data * data_dim.final_score
            + self.weights.w_content * content_dim.final_score
            + self.weights.w_compliance * compliance_dim.final_score
            + self.weights.w_conversion * conversion_dim.final_score
        )

        # 3. 确定健康等级
        health_level = HealthLevel.from_score(total_score)

        # 4. 生成优化建议
        suggestions = self._generate_suggestions(
            data_dim, content_dim, compliance_dim, conversion_dim
        )

        return HealthScoreResult(
            account_id=account_id,
            platform_uid=platform_uid,
            score_date=score_date,
            total_score=round(total_score, 2),
            health_level=health_level.name,
            dimensions={
                "data": data_dim,
                "content": content_dim,
                "compliance": compliance_dim,
                "conversion": conversion_dim,
            },
            weights=self.weights,
            suggestions=suggestions,
        )

    def _calc_data_dimension(
        self, account_data: dict, notes_data: list[dict]
    ) -> DimensionScore:
        """计算数据指标维度评分"""
        indicators = {}

        # 粉丝量得分 (对数映射)
        fans = account_data.get("fans_count", 0)
        fans_score = min(100, np.log10(max(fans, 1)) / np.log10(1000000) * 100)
        indicators["fans_score"] = round(fans_score, 2)

        # 粉丝增长率得分
        fans_growth_rate = account_data.get("fans_growth_rate", 0)
        if fans_growth_rate > 5:
            growth_score = 100
        elif fans_growth_rate > 2:
            growth_score = 80
        elif fans_growth_rate > 0:
            growth_score = 60
        elif fans_growth_rate > -2:
            growth_score = 40
        else:
            growth_score = 20
        indicators["fans_growth_score"] = growth_score

        # 互动率得分
        interaction_rate = account_data.get("interaction_rate", 0)
        if interaction_rate >= 0.08:
            ir_score = 100
        elif interaction_rate >= 0.05:
            ir_score = 85
        elif interaction_rate >= 0.03:
            ir_score = 70
        elif interaction_rate >= 0.01:
            ir_score = 50
        else:
            ir_score = 30
        indicators["interaction_rate_score"] = ir_score

        # 发布活跃度得分
        publish_freq = account_data.get("publish_frequency", 0)
        if publish_freq >= 1.0:
            pub_score = 100
        elif publish_freq >= 0.5:
            pub_score = 80
        elif publish_freq >= 0.3:
            pub_score = 60
        else:
            pub_score = 30
        indicators["publish_score"] = pub_score

        # 加权平均
        dim_score = (
            0.20 * fans_score
            + 0.25 * growth_score
            + 0.35 * ir_score
            + 0.20 * pub_score
        )

        # 异常惩罚
        penalty = 0.0
        penalty_reasons = []
        if fans_growth_rate < -0.01:
            penalty += 10
            penalty_reasons.append(f"粉丝持续流失（日流失率 {fans_growth_rate:.2%}）")
        if publish_freq < 0.1:
            penalty += 10
            penalty_reasons.append("发布频率过低，存在停更风险")

        return DimensionScore(
            name="数据指标",
            score=round(dim_score, 2),
            indicators=indicators,
            penalty=penalty,
            penalty_reasons=penalty_reasons,
        )

    def _calc_content_dimension(
        self, account_data: dict, notes_data: list[dict]
    ) -> DimensionScore:
        """计算内容质量维度评分"""
        indicators = {}

        # 原创率得分
        total_notes = len(notes_data)
        original_notes = sum(1 for n in notes_data if n.get("is_original", True))
        original_rate = original_notes / max(total_notes, 1)
        orig_score = min(100, original_rate * 100)
        indicators["original_rate_score"] = round(orig_score, 2)
        indicators["original_rate"] = round(original_rate, 4)

        # 爆款率得分
        if notes_data:
            avg_reads = np.mean([n.get("read_count", 0) for n in notes_data])
            viral_notes = sum(
                1 for n in notes_data if n.get("read_count", 0) > avg_reads * 3
            )
            viral_rate = viral_notes / max(total_notes, 1)
            viral_score = min(100, viral_rate * 500)  # 20% 爆款率 = 100 分
        else:
            viral_rate = 0
            viral_score = 0
        indicators["viral_rate_score"] = round(viral_score, 2)

        # CQI 得分
        if notes_data:
            avg_cqi = np.mean([n.get("cqi", 0) for n in notes_data])
            if avg_cqi >= 0.08:
                cqi_score = 100
            elif avg_cqi >= 0.05:
                cqi_score = 80
            elif avg_cqi >= 0.03:
                cqi_score = 60
            else:
                cqi_score = 40
        else:
            avg_cqi = 0
            cqi_score = 0
        indicators["cqi_score"] = cqi_score

        # 内容垂直度得分 (基于标签离散度)
        all_tags = []
        for n in notes_data:
            all_tags.extend(n.get("tags", []))
        if all_tags:
            from collections import Counter
            tag_counts = Counter(all_tags)
            total = sum(tag_counts.values())
            # 使用归一化熵衡量垂直度
            entropy = -sum(
                (c / total) * np.log2(c / total)
                for c in tag_counts.values()
            )
            max_entropy = np.log2(len(tag_counts))
            verticality = 1 - (entropy / max_entropy if max_entropy > 0 else 0)
            vert_score = verticality * 100
        else:
            vert_score = 50  # 无数据给中间值
        indicators["verticality_score"] = round(vert_score, 2)

        # 加权平均
        dim_score = (
            0.20 * orig_score
            + 0.25 * viral_score
            + 0.30 * cqi_score
            + 0.25 * vert_score
        )

        return DimensionScore(
            name="内容质量",
            score=round(dim_score, 2),
            indicators=indicators,
        )

    def _calc_compliance_dimension(
        self, compliance_data: dict
    ) -> DimensionScore:
        """计算合规与风险维度评分"""
        indicators = {}
        penalty = 0.0
        penalty_reasons = []

        # 违规记录
        violation_count = compliance_data.get("violation_count_180d", 0)
        if violation_count == 0:
            violation_score = 100
        elif violation_count == 1:
            violation_score = 60
            penalty += 20
            penalty_reasons.append("近 180 天有 1 次违规记录")
        else:
            violation_score = 20
            penalty += 40
            penalty_reasons.append(f"近 180 天有 {violation_count} 次违规记录")
        indicators["violation_score"] = violation_score

        # 广告标注合规率
        ad_compliance_rate = compliance_data.get("ad_compliance_rate", 1.0)
        ad_score = ad_compliance_rate * 100
        if ad_compliance_rate < 1.0:
            penalty += 10
            penalty_reasons.append(
                f"广告标注合规率 {ad_compliance_rate:.0%}，存在未标注广告"
            )
        indicators["ad_compliance_score"] = round(ad_score, 2)

        # 内容审核通过率
        audit_pass_rate = compliance_data.get("audit_pass_rate", 1.0)
        audit_score = audit_pass_rate * 100
        indicators["audit_pass_score"] = round(audit_score, 2)

        # 限流风险指数
        shadowban_risk = compliance_data.get("shadowban_risk", 0.0)
        if shadowban_risk < 0.1:
            sb_score = 100
        elif shadowban_risk < 0.3:
            sb_score = 60
            penalty += 15
            penalty_reasons.append("检测到限流风险信号")
        else:
            sb_score = 20
            penalty += 30
            penalty_reasons.append("限流风险较高，建议排查原因")
        indicators["shadowban_score"] = sb_score

        dim_score = (
            0.30 * violation_score
            + 0.25 * ad_score
            + 0.20 * audit_score
            + 0.25 * sb_score
        )

        return DimensionScore(
            name="合规风险",
            score=round(dim_score, 2),
            indicators=indicators,
            penalty=penalty,
            penalty_reasons=penalty_reasons,
        )

    def _calc_conversion_dimension(
        self, account_data: dict
    ) -> DimensionScore:
        """计算转化能力维度评分"""
        indicators = {}

        # 粉丝画像质量
        fan_quality = account_data.get("fan_quality_score", 0.5)
        fq_score = fan_quality * 100
        indicators["fan_quality_score"] = round(fq_score, 2)

        # CPE 合理性
        cpe = account_data.get("cpe", 0)
        avg_cpe = account_data.get("category_avg_cpe", 0)
        if cpe > 0 and avg_cpe > 0:
            cpe_ratio = avg_cpe / cpe
            cpe_score = min(100, max(0, cpe_ratio * 80))
        else:
            cpe_score = 50
        indicators["cpe_score"] = round(cpe_score, 2)

        # 商业价值稳定性
        value_stability = account_data.get("value_stability", 0.8)
        stab_score = value_stability * 100
        indicators["stability_score"] = round(stab_score, 2)

        dim_score = (
            0.35 * fq_score
            + 0.35 * cpe_score
            + 0.30 * stab_score
        )

        return DimensionScore(
            name="转化能力",
            score=round(dim_score, 2),
            indicators=indicators,
        )

    def _generate_suggestions(
        self,
        data_dim: DimensionScore,
        content_dim: DimensionScore,
        compliance_dim: DimensionScore,
        conversion_dim: DimensionScore,
    ) -> list[str]:
        """基于评分短板生成优化建议"""
        suggestions = []

        # 数据指标建议
        if data_dim.final_score < 60:
            if data_dim.indicators.get("interaction_rate_score", 0) < 50:
                suggestions.append(
                    "💡 互动率偏低：建议优化内容标题和封面，增加互动引导 "
                    "（如提问、投票等），提升用户参与度"
                )
            if data_dim.indicators.get("publish_score", 0) < 50:
                suggestions.append(
                    "💡 发布频率不足：建议保持每周至少 3-4 篇笔记的发布频率，"
                    "维持账号活跃度"
                )

        # 内容质量建议
        if content_dim.final_score < 60:
            if content_dim.indicators.get("original_rate_score", 0) < 60:
                suggestions.append(
                    "💡 原创率偏低：建议提升原创内容比例，减少搬运和二次创作"
                )
            if content_dim.indicators.get("verticality_score", 0) < 50:
                suggestions.append(
                    "💡 内容垂直度不足：建议聚焦核心赛道，减少与账号定位无关的内容"
                )

        # 合规风险建议
        if compliance_dim.penalty_reasons:
            suggestions.append(
                "⚠️ 存在合规风险：请及时处理违规内容，确保商业合作笔记正确标注"
            )

        # 转化能力建议
        if conversion_dim.final_score < 60:
            suggestions.append(
                "💡 转化能力有提升空间：建议优化粉丝画像，"
                "提升内容与目标受众的匹配度"
            )

        if not suggestions:
            suggestions.append("✅ 账号整体状态良好，请继续保持当前运营策略")

        return suggestions
```

### 12.1 数据安全

| 安全措施 | 实现方式 |
|---------|---------|
| 传输加密 | 全链路 HTTPS (TLS 1.3)，API 通信强制 HTTPS |

### 12.2 API 安全

```python
from fastapi import Depends, HTTPException, Security
from fastapi.security import APIKeyHeader

API_KEY_HEADER = APIKeyHeader(name="X-API-Key")

async def verify_api_key(api_key: str = Security(API_KEY_HEADER)):
    """API Key 验证"""
    if not api_key or not await validate_key(api_key):
        raise HTTPException(status_code=403, detail="Invalid API Key")
    return api_key

# 速率限制
from slowapi import Limiter
```

### 12.3 合规治理

| 措施 | 说明 |
|------|------|
| 数据来源合规 | 仅通过蒲公英官方 API 和正规第三方数据平台获取数据 |

## 15. 风险评估与应对

### 15.1 风险矩阵

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| **蒲公英 API 权限申请被拒** | 中 | 高 | 提前申请，准备第三方平台作为备选方案 |
| **第三方平台 API 变更/停服** | 中 | 高 | 适配器模式解耦，支持快速切换数据源 |
| **数据质量不稳定** | 高 | 中 | 建立数据质量监控，异常数据自动标记 |
| **平台反爬升级影响数据采集** | 低 | 高 | 不依赖爬虫，仅使用合规 API |
| **评分模型准确度不足** | 中 | 中 | 上线后持续收集反馈，迭代优化模型 |
| **合规政策变化** | 中 | 高 | 持续关注法规动态，预留合规调整空间 |
| **系统性能瓶颈** | 低 | 中 | 水平扩展设计，关键服务支持多实例部署 |

### 15.2 应急预案

| 场景 | 应急措施 |
|------|---------|
| 数据源不可用 | 切换到备选数据源，使用缓存数据提供降级服务 |
| 评分引擎异常 | 回退到上一日评分结果，记录异常日志并告警 |
| 数据库故障 | 自动切换到从库，启动数据恢复流程 |
| 系统过载 | 触发限流策略，优先保障评分计算核心链路 |
